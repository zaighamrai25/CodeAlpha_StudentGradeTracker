# Student Grade Tracker - Java Internship Project

>  Console-based Java project to manage student grades using **OOP** and **ArrayList**  
> Developed as part of **CodeAlpha Internship**  

---

##  Features

- Add and manage student records (ID, Name, Marks)  
- Calculate **Average Marks**, **Highest Marks**, and **Lowest Marks**  
- Display **summary report** of all students in a clean table format  
- Object-Oriented Programming (OOP) concepts implemented:
  - Classes & Objects (`Student`& `StudentManager`)  
  - Encapsulation & Getter/Setter methods  
  - ArrayList for dynamic data storage  
- Menu-driven **console interface** for easy interaction
